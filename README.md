Learnify – Online Learning Website

About the Project :
Learnify is a responsive educational website designed to provide users with a simple and user-friendly learning experience. 
It is developed using HTML, CSS, and Bootstrap to create an attractive and responsive interface.

Objectives :
-> Create a clean and user-friendly educational website.
-> Provide an organised layout for online learning.
-> Build a responsive design that works across different screen sizes.
-> Improve practical knowledge of frontend web development.

Technologies Used :
-> HTML – Website structure
-> Bootstrap – Responsive layout and components

Features :
-> Responsive website design
-> User-friendly interface
-> Bootstrap-based components
-> Clean and organised layout
